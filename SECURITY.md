# Security Policy

Pomo Pet is a local-first timer app. Please report security issues privately
instead of opening a public issue when they involve data exposure, unsafe
downloads, package publishing, or browser storage behavior.

## Supported Versions

Security fixes target the current `main` branch and the latest public release.

## Reporting

Open a private GitHub security advisory for this repository, or contact the
maintainer through the GitHub profile linked from the project. Include:

- A short description of the issue
- Steps to reproduce
- The affected surface, such as CLI, desktop app, web app, service worker, or
  installer
- Any suggested mitigation

Please avoid sharing exploit details publicly until a fix is available.
